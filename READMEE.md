## 🚀 Featured projects

### 🏥 [CARE — Clinical Agentic Reliability Engine](https://github.com/saidivyakatakamsetty/CARE)
Agentic early-warning system for sepsis built on real ICU data (PhysioNet/CinC 2019). Engineers rolling clinical trend features, scores deterioration risk with a hybrid XGBoost + Isolation Forest model tracked in MLflow, and runs a LangGraph multi-agent workflow that grounds recommendations in retrieved clinical evidence (RAG), served through FastAPI.
`Python` `XGBoost` `MLflow` `LangGraph` `RAG` `ChromaDB` `FastAPI` `SQLite`

### 🩺 [MediBot — Medical RAG Chatbot](https://github.com/saidivyakatakamsetty/medibot)
RAG-based medical Q&A chatbot that answers questions grounded in medical documents, using Hugging Face embeddings and FAISS semantic search, evaluated with RAGAS faithfulness scoring, with a Streamlit interface.
`Python` `LangChain` `FAISS` `Hugging Face` `RAGAS` `Streamlit`

### 🎯 [VisionAI — Real-Time Object Detection](https://github.com/saidivyakatakamsetty/object-detection-app)
Real-time object detection app powered by YOLOv8 and Gradio, detecting 80+ object classes in images, videos, and live webcam feeds.
`Python` `YOLOv8` `OpenCV` `Gradio`

### 🏋️ [AI Fitness Form Analyzer](https://github.com/saidivyakatakamsetty/fitness_analyzer)
Computer vision app that detects exercise movements through a webcam, counts reps for squats, pushups, and lunges, and tracks workouts on a dashboard.
`Python` `Computer Vision` `Pose Estimation`

### 🔢 [Handwritten Digit Recognizer from Scratch](https://github.com/saidivyakatakamsetty/Digit-Recognizer)
2-layer neural network built with pure NumPy (no frameworks), implementing forward propagation, backpropagation, and gradient descent, with ~89–91% accuracy on MNIST and a live drawing app.
`Python` `NumPy` `Neural Networks` `Tkinter`
